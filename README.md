# SAD Assignment — Patient Care

## Overview

This repository contains my Software Architecture and Design (SAD) assignment for a Patient Care System.

The assignment focuses on identifying the domain context, bounded contexts, entities, and user stories within a healthcare patient care system.

## Contents

### 1. Context Diagram

The `CONTEXT-DIAGRAM.md` file presents the domain context map and the main bounded contexts of the Patient Care System.

It includes:

* Patient Management
* Billing & Insurance Claims
* Lab Test Diagnostics

### 2. User Stories

The `USER-STORIES.md` file contains the domain context mapping and two user stories:

* Appointment Rescheduling
* Viewing Lab Test Results

Each user story includes acceptance criteria and scenarios describing the expected system behaviour.
